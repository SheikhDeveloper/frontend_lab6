# Vue 3 Lab Works

Проект представляет собой сборник лабораторных работ по Vue 3, демонстрирующих различные аспекты современной фронтенд-разработки. Каждая лабораторная работа реализует Todo-приложение с разными технологическими подходами.

## 🧪 Лабораторные работы

### Lab 12: Работа с API и Composition API
**Маршрут:** `/lab12`

**Технологии:** Vue 3 Composition API, Axios, LocalStorage

**Особенности:**
- Загрузка данных с внешнего API (JSONPlaceholder)
- Реализация собственного композабл-хранилища (`useTodoStore.ts`)
- Всплывающие окна для подтверждения действий
- Сохранение состояния в LocalStorage
- Адаптивная вёрстка

**Ключевые файлы:**
- `src/views/Lab12View.vue` - Основной компонент
- `src/composables/useTodoStore.ts` - Хранилище задач
- `src/components/TodoForm.vue` - Форма добавления
- `src/components/TodoItem.vue` - Элемент списка
- `src/components/Popup.vue` - Всплывающее окно

### Lab 13: Валидация форм с VeeValidate
**Маршрут:** `/lab13`

**Технологии:** VeeValidate 4, Yup, Composition API

**Особенности:**
- Полная валидация форм с помощью VeeValidate
- Схемы валидации с использованием Yup
- Локализация сообщений об ошибках
- Кастомные правила валидации
- Визуальная обратная связь при ошибках

**Ключевые файлы:**
- `src/views/Lab13View.vue` - Основной компонент
- `src/components/TodoForm.vue` - Форма с валидацией
- `src/composables/useTodoStore.ts` - Общее хранилище

### Lab 14: Маршрутизация (Vue Router)
**Маршрут:** `/lab14`

**Технологии:** Vue Router, Вложенные маршруты, Composition API

**Особенности:**
- Полноценная SPA с клиентской маршрутизацией
- Вложенные маршруты для операций с задачами
- Динамические параметры маршрутов (`/task/:id`)
- Программная навигация
- Отдельные страницы для каждой операции

**Маршруты Lab 14:**
- `/lab14/` - Список задач со статистикой
- `/lab14/add` - Добавление новой задачи
- `/lab14/task/:id` - Просмотр деталей задачи
- `/lab14/task/:id/delete` - Подтверждение удаления
- `/lab14/task/:id/complete` - Изменение статуса задачи
- `/lab14/about` - Страница "О нас"

**Ключевые файлы:**
- `src/views/Lab14View.vue` - Родительский компонент
- `src/components/TaskList.vue` - Список задач
- `src/components/TaskForm.vue` - Форма добавления
- `src/components/TaskDetails.vue` - Детали задачи
- `src/components/TaskDelete.vue` - Удаление задачи
- `src/components/TaskComplete.vue` - Изменение статуса
- `src/components/About.vue` - Страница "О нас"
- `src/composables/useLab14TodoStore.ts` - Специализированное хранилище

### Lab 15: Управление состоянием с Pinia
**Маршрут:** `/lab15`

**Технологии:** Pinia, Composition API, TypeScript

**Особенности:**
- Централизованное управление состоянием через Pinia
- Строгая типизация хранилища
- Геттеры для вычисляемых свойств
- Действия для бизнес-логики
- Интеграция с Vue DevTools
- Современный UI/UX дизайн

**Ключевые файлы:**
- `src/views/Lab15View.vue` - Основной компонент
- `src/stores/todo.ts` - Pinia хранилище задач
- `src/types/todo.ts` - Типы TypeScript
